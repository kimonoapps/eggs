# Kimono Hosting eggs

Pelican eggs for apps hosted on Kimono Hosting. Import the JSON file in the Pelican admin panel; each app's folder
explains its setup.

| Egg | App | Setup |
| --- | --- | --- |
| `egg-read.json` | Read: app, PostgreSQL and optional Cloudflare Tunnel in one server; demo mode works with no setup | [`read/`](read/README.md) |
| `egg-authentik.json` | Authentik (server + worker), for Read's school accounts | [`read/`](read/README.md) |
| `egg-belagirkahoot.json` | Jeunesse Bel Agir live quiz | [`belagirkahoot/`](belagirkahoot/README.md) |
| `egg-shawarma-sinbad.json` | Shawarma Sinbad | [`shawarma-sinbad/`](shawarma-sinbad/README.md) |
| `egg-palworld-ddns.yaml` | Palworld with startup DDNS | — |
